Whose move is it — three ways to say so

The chip on the Scope step is a button that opens the document's state card, and today it reads as a status dot. Each option below pairs a copy change with a visual one, shown in both states: when the move is yours, and when it belongs to someone else. Hover them — the hover state is part of the answer.

NowWhat ships today

Two problems in one mark. “You” names an identity, not an obligation — it could as easily mean “this is you” as “this is yours to move”. And the pill has no affordance, so it reads like the avatar chips beside it. The copy that would fix it already exists: the chip's title is “Your move — click for detail”, visible only on hover.

Option 1Promote the tooltip, add a caret

Says the obligation out loud and borrows the chevron the bar already uses for “this opens something” — same glyph as the role button to its right. Smallest possible change, and it stops hiding the clearest copy in the feature. Costs about 45px of bar width, which is fine at this step and tighter where step labels run long.

Option 2The shape the bar's other controls use

Squared, bordered, with a caret — the treatment of Role · Admin a few inches to the right. Reusing a control pattern already learned in this same black bar is the strongest clickability signal available. It also splits the two jobs the yellow is doing: the dot carries ownership, the button shape carries clickability, so the accent stops competing with the yellow CTA beside it.

Option 3Identity in the bar, obligation in the caption

The chip goes back to being a quiet identity mark and stops pretending to be a button. What you owe moves to the caption line under the step — which already exists, and is already where “what happens next” copy lives — as a text link, which nobody has to be taught is clickable. Quietest in the bar, but the cue is no longer on the thing you were looking at.
